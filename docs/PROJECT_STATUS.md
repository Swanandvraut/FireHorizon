# FireHorizon — Project Status

## Completed
- Selected the NASA challenge: Harmonization of MODIS and VIIRS Hot Spots.
- Created a NASA Earthdata account.
- Submitted four NASA FIRMS archive requests for India, 2025-03-01 through 2025-03-31.
- Downloaded all four ZIP archives.
- Audited the CSV schema and row counts.
- Combined 652,025 observations while preserving source provenance and sensor-specific confidence encoding.
